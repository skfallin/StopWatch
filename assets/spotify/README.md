L'icona Spotify proviene dalle [linee guida ufficiali](https://developer.spotify.com/documentation/design).
`icon-framed.svg` è il file originale; `src/spotify_icon.h` contiene la maschera monocromatica dell'icona a 24×24 pixel per il display.
Marchio e risorsa appartengono a Spotify. Nessun logo è sovrapposto alla copertina.
